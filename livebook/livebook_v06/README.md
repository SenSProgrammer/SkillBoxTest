# LiveBook v1 Prototype (MVP scaffold)

This archive contains:
- **backend/** Node.js + Fastify (TypeScript) REST API with core endpoints (`/ext/rc/*`, `/ext/cross/*`, `/editor/*`, `/experts/*`, `/articles/*`).
- **openapi/** OpenAPI 3.1 spec (`livebook.yaml`).
- **spaas/** Four minimal SPA shells to host in Object Storage (user, editor, expert, author).
- **sample/** Example JSON manifests for articles (“ТИУС” and “ТИУС — анекдоты и загадки”).
- **deploy-checklist.md** Step-by-step deployment checklist.
- **.env.example** for backend configuration.

> This is a *skeleton* meant to compile and run locally with mocked persistence.
